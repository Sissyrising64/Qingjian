# 轻拣 2.0.4：启动状态与恢复按钮修复

## 修复内容

1. 窗口创建完成时立即同步撤销/恢复按钮状态，不再等待首轮事件循环。
2. 未选择来源文件夹时，撤销和恢复按钮始终禁用；即使本地日志保留了上一工作区的记录，也不会误显示为可操作。
3. 中文按钮由“重做”改为“恢复上一步”，完成提示改为“已恢复上一步”，含义更直接。
